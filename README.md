# Self-Employment Start Platform

Social and technological platform for supporting self-employment,
professional development and access to relevant opportunities.

The project follows an architecture-first approach.

The architecture, principles and implementation are openly documented.
External commercial services are integrated through defined interfaces
and do not form part of the project core unless explicitly specified.

## Author

Olga Mikhailova

## Architecture

The project is based on the principles of Universal Block Architecture
(UBA), adapted for the social, educational and professional domain.

## Transparency

The project does not rely on hidden architectural dependencies.

Core principles, documented interfaces and security requirements are
available for public review.

Commercial integrations remain explicitly separated from the project core.
