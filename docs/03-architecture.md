# Архитектура / Architecture

## RU

Архитектура основана на Universal Block Architecture (UBA) и расширена для социальной, образовательной и профессиональной области.

Базовые инварианты UBA:

- блок;
- сцепка;
- транспорт;
- состояние;
- безопасность;
- интеграция.

Доменные блоки:

- соискатель;
- тестирование;
- возможности;
- образование;
- активности;
- стартовый комплект;
- данные и приватность;
- интеграции.

Внешние системы подключаются через определённые интерфейсы.

Ядро проекта не зависит от конкретного коммерческого партнёра.

## EN

The architecture is based on Universal Block Architecture (UBA) and extended for the social, educational and professional domain.

UBA invariants:

- block;
- coupling;
- transport;
- state;
- security;
- integration.

Domain blocks:

- candidate;
- assessment;
- opportunities;
- education;
- activities;
- starter package;
- data and privacy;
- integrations.

External systems are connected through defined interfaces.

The project core remains independent of individual commercial partners.
