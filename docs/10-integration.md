# Интеграции / Integrations

## RU

Внешние системы могут включать:

- платформы поиска работы;
- образовательные платформы;
- финансовые сервисы;
- партнёрские сервисы;
- AI-сервисы.

Каждая интеграция должна иметь определённый интерфейс и назначение.

Интеграция не означает владение внешними данными.

Функциональность конкретного партнёра остаётся за пределами ядра проекта, если отдельно не определено иное.

---

## EN

External systems may include:

- employment platforms;
- educational platforms;
- financial services;
- partner services;
- AI services.

Each integration must have a defined interface and purpose.

Integration does not imply ownership of external data.

Partner-specific functionality remains outside the project core unless explicitly defined otherwise.
