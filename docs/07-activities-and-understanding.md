# Активности и понимание / Activities and Understanding

## RU

Платформа может предоставлять короткие активности для проверки того, понимает ли пользователь текущую тему.

Пример:

> Самозанятость — это ...

Пользователь получает простое объяснение и может пройти короткий тест на понимание.

Возможные результаты:

- подтверждение понимания;
- следующий учебный шаг;
- купон;
- промокод;
- переход к сервису;
- изменение статуса.

Активность должна создавать полезное взаимодействие, а не заменять его рекламным предложением.

---

## EN

The platform may provide short activities to check whether the user understands the current topic.

Example:

> Self-employment is ...

The user receives a simple explanation and may take a short understanding test.

Possible results:

- confirmation of understanding;
- next learning step;
- coupon;
- promo code;
- transition to a service;
- status change.

An activity should create useful interaction rather than simply replace it with advertising.
