# Тестирование / Testing

## RU

Тестирование следует циклу разработки:

Документация
→ Код
→ Прототип
→ Тестирование
→ Документация

Проверяются:

- блоки;
- интерфейсы;
- поток данных;
- сохранение информации;
- требования безопасности;
- интеграции;
- пользовательские активности.

Техническое тестирование и оценка соискателя являются разными функциями.

Результат технического теста не определяет профессиональную ценность человека.

---

## EN

Testing follows the development cycle:

Documentation
→ Code
→ Prototype
→ Testing
→ Documentation

Testing covers:

- blocks;
- interfaces;
- data flow;
- information preservation;
- security requirements;
- integrations;
- user activities.

Technical testing and candidate assessment are separate functions.

The result of a technical test does not determine a person's professional value.
