# Данные и приватность / Data and Privacy

## RU

Проект использует только данные, доступные ему на соответствующем правовом и техническом основании.

Проект не предполагает доступа к данным партнёров без явно определённой интеграции.

Принципы:

- минимизация данных;
- определённая цель обработки;
- контролируемый доступ;
- разделение ядра и внешних систем;
- явная передача данных;
- аудитируемость.

Требования к персональным данным определяются до реализации соответствующей функциональности.

---

## EN

The project uses only data available to it on an appropriate legal and technical basis.

The project does not assume access to partner data without an explicitly defined integration.

Principles:

- data minimization;
- defined processing purpose;
- controlled access;
- separation of the core and external systems;
- explicit data exchange;
- auditability.

Personal data requirements are defined before implementing the corresponding functionality.
