# Образовательный слой / Education Layer

## RU

Образовательный слой связывает профессиональное тестирование с дальнейшим обучением.

Базовый поток:

Вход
→ Учебный маршрут
→ Практика
→ Проверка
→ Результат

Возможны:

- предложения сторонних курсов;
- образовательные организации;
- собственная образовательная программа проекта;
- обучение с непосредственным участием ИИ.

Платный и бесплатный контуры используют одинаковые содержание и подачу информации.

Различия могут относиться к доступу, сопровождению и дополнительным сервисам.

Статус: в разработке.

---

## EN

The education layer connects professional assessment with further learning.

Basic flow:

Input
→ Learning Path
→ Practice
→ Assessment
→ Result

Possible sources include:

- third-party courses;
- educational institutions;
- the project's own educational program;
- learning with direct AI participation.

Paid and free contours use the same content and information presentation.

Differences may concern access, support and additional services.

Status: in development.
