# Блоки / Blocks

## RU

### Соискатель

Профиль пользователя и информация, предоставленная им.

### Тестирование

Тесты и активности для определения знаний, понимания, навыков и профессионального соответствия.

### Возможности

Вакансии, возможности самозанятости и партнёрские предложения.

### Образование

Образовательный контент, учебные маршруты и оценка результатов.

Статус: в разработке.

### Активности

Короткие интерактивные задания для проверки понимания и вовлечённости.

### Стартовый комплект

Набор сервисов, которые могут потребоваться для начала или поддержки самозанятости.

### Данные и приватность

Правила сбора, обработки, хранения и передачи данных.

### Интеграции

Интерфейсы взаимодействия с внешними платформами и сервисами.
