# Стартовый комплект / Starter Package

## RU

Стартовый комплект — набор сервисов, который может использоваться для начала или поддержки самозанятости.

Возможные компоненты:

- банковская карта;
- SIM / eSIM;
- страхование;
- цифровые сервисы;
- образовательные ресурсы;
- профессиональные инструменты.

Состав зависит от выбранного пользователем маршрута и доступных интеграций.

Коммерческие партнёры подключаются на основании отдельных условий и договоров.

---

## EN

The Starter Package is a set of services that may support the start or continuation of self-employment.

Possible components:

- bank card;
- SIM / eSIM;
- insurance;
- digital services;
- educational resources;
- professional tools.

The package depends on the user's selected route and available integrations.

Commercial partners are connected under separate terms and agreements.
