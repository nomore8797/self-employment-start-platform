# Обзор / Overview

## RU

Проект представляет собой социально-технологическую платформу для поддержки самозанятости, профессионального развития и доступа к подходящим возможностям.

Основной поток:

Пользователь
→ Тестирование
→ Профиль соискателя
→ Возможности
→ Образование
→ Трудовая деятельность / Самозанятость
→ Дополнительные сервисы

Платформа может включать:

- вакансии и коммерческие офферы;
- образовательные курсы и организации;
- собственную образовательную программу с участием ИИ;
- стартовые комплекты для самозанятости;
- партнёрские сервисы;
- маршруты профессионального развития.

## EN

The project is a social and technological platform supporting self-employment, professional development and access to relevant opportunities.

Core flow:

User
→ Assessment
→ Candidate Profile
→ Opportunities
→ Education
→ Employment / Self-employment
→ Additional Services

The platform may include:

- vacancies and commercial offers;
- educational courses and institutions;
- the project's own AI-assisted educational program;
- self-employment starter packages;
- partner services;
- professional development routes.
